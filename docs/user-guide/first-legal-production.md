# Primeira Producao Juridica (MVP)

1. Abra a aplicacao web.
2. Crie um novo caso.
3. Selecione a skill "Contestacao Saude (MVP)".
4. Importe ou anexe fontes.
5. Clique em "Processar Fontes de IA".
6. Gere diagnostico, teses e arquitetura.
7. Gere os capitulos.
8. Revise os blocos no painel de revisao.
9. Baixe o DOCX final.

Se estiver sem chave de API, o sistema opera em modo mock automaticamente.
