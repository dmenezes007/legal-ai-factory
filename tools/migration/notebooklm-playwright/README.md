# Modulo Experimental NotebookLM + Playwright

Este modulo e experimental e desacoplado do fluxo principal do MVP.

## Objetivo

Investigar a viabilidade tecnica de automacao assistida por navegador para apoiar exportacao de fontes do NotebookLM.

## Regras

- Nao usar este modulo como dependencia obrigatoria do produto.
- Nao executar scraping agressivo.
- Respeitar termos de uso da plataforma externa.
